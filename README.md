## 🛠️ Technology Stack

- **Framework:** React 18 + Vite + TypeScript
- **Styling:** Tailwind CSS + PostCSS + Autoprefixer
- **Animations:** Framer Motion (smooth spring physics, staggered entrances, layout transitions)
- **Icons:** Lucide React
- **Celebration Effects:** Canvas Confetti
- **Deployment Platform:** Vercel (`vercel.json` configured for SPA routing and asset caching)

## ⚡ Deployment to Vercel

1. **Push to GitHub:** This project is hosted at `https://github.com/taezeem14/ahmad-digital-printers`.
2. **Import to Vercel:**
   - Log in to your [Vercel Dashboard](https://vercel.com).
   - Click **Add New Project** and select `ahmad-digital-printers`.
   - Vercel automatically detects **Vite**:
     - **Build Command:** `npm run build`
     - **Output Directory:** `dist`
     - **Install Command:** `npm install`
   - Click **Deploy**!
3. The site will be live on your custom `.vercel.app` domain in under 45 seconds.
